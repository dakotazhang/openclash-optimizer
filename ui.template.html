OpenClash 分流助手

网站去哪条线路、DNS 怎么查询，用表单管理。保留你已有的订阅和设置，生成一个可直接粘贴的覆写文件。

所有处理都在你的浏览器里完成。不需要路由器密码，不上传原配置，不连接任何分析服务。此页是配置生成工具，不是测速或自动诊断工具。

① 选择主代理组与 DNS

AUTO 优先找 TAGSS，否则选择现有第一个 select 组。建议到 Dashboard 看清名称后填写；该组应选中可用代理节点。

阿里／腾讯 DoH 为默认解析；Cloudflare／Google DoH 经主代理组作为备用。保留 DNS 监听端口、运行模式、IPv6与嗅探设置。

② 给网站分组

每行一个网址或纯域名。精确匹配只管这个主机；包含子域名同时管它的下级域名。上面的组优先，具体例外应放前面。

高级：Tracker 直连与 DNS 例外

例：chdbits.co foreign。只改变 DNS 查询出口，不改变网站访问的策略组。

③ 导入原覆写文件

在 OpenClash「运行状态 → 覆写模块」点击下载，把下载的 openclash_custom_overwrite.sh 放进这里。工具会保留其中的原有配置，追加自己的管理段。

④ 保存备份，再粘贴配置

先保存原文件备份，再复制生成内容。回到覆写模块，全选旧内容、粘贴新内容、保存，随后重启 OpenClash。首次会重载代理连接，请在方便排查网络的时段操作。

生成器只能检查表单和合并结构。路由器执行时还会用 Mihomo 检查候选配置；检查失败不会写入本工具生成的配置。恢复方法：粘贴原文件备份、保存并重启。
